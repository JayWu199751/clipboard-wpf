# 思源黑体字体资源

- 来源：[Adobe Source Han Sans 官方仓库 2.005R](https://github.com/adobe-fonts/source-han-sans/tree/2.005R/SubsetOTF/CN)。
- 配置：官方简体中文子集静态 OTF，内部字体族名 `Source Han Sans CN`。
- 字重：Regular（400）与 Medium（500），对应现有界面字重；文件未经修改。
- 许可：SIL Open Font License 1.1，完整版权与许可见 [LICENSE.txt](LICENSE.txt)。许可随构建及发布复制到相同相对路径。
- 使用：作为 WPF `Resource` 内置，`Font.Sans` 引用；无需向 Windows 安装字体。
- 范围：面板和托盘菜单普通文字；`Font.Mono` 的等宽字体保持原回退链。
- 缺字：沿用 Segoe UI 与系统字体回退，不裁剪用户的剪贴板内容。
