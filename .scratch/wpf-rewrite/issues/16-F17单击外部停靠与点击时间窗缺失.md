# 16: F17 单击外部停靠与点击时间窗缺失

Execution: claimed (fix-review, 2026-10-04)——终审两轴评审开出。

## 功能编号

F17（单击外部停靠；圆角外透明部分鼠标穿透，下层可收到点击；全局钩子记录真实点击时间，早于本次呼出的点击不能将刚呼出面板收起）。

## 事实

终审评审确认覆盖表对本功能的归属有误判：F17 的③「全局钩子记录真实点击时间 + 时间窗防护」
在 WPF 重写中**完全缺失**——map.md 覆盖表把 F17 记在 T01 行（连同 F15/F16），但 T01 只做了
F15/F16（几何/停靠/穿透），验收矩阵 F17 行引用的「PanelModes hides_on_click」实为 legacy
侧实现（panel_modes.rs），CornerHitGeometry 只覆盖圆角穿透（F17 的②，已达成）：
「单击外部停靠」（①）与「点击时间窗」（③）没有任何对应实现——无 MouseHook、无外部点击判定、
无呼出时刻记录。规格原句：

> F17 | 单击外部停靠；圆角外透明部分鼠标穿透，下层可收到点击；全局钩子记录真实点击时间，早于本次呼出的点击不能将刚呼出面板收起

legacy 事实源：`click_watcher.rs`（WH_MOUSE_LL 钩子线程 + 转发线程，回调只记录坐标与按下时刻）、
`panel_modes.rs::hides_on_click`（`shown_at.is_some_and(|shown| clicked_at > shown)`）、
`modes.rs::hide_if_clicked_outside`（面板可见 → 时间窗判定（早于呼出记
`click_ignored predates_show` 不动作）→ `hit_test == Some(false)` 才 hide；
窗口缺失或几何读不到（None）不隐藏，免得面板莫名收起）。
圆角外透明区不参与隐藏决策（legacy hit_test 是矩形判定，穿透由渲染层负责——P5/ADR-0006 同构）。

## 完成判据

- [ ] Domain 纯规则收口外部点击判定（可见性、呼出时刻 vs 点击时刻、坐标 vs 窗口物理矩形 → 应否停靠），
      全量单测；时刻比较语义与 legacy hides_on_click 逐条对齐（严格晚于才收；从没呼出不收）。
- [ ] Application/编排接线：呼出时刻在 Show 时记录；钩子事件归队 UI 线程判定，判定通过走停靠编排

- `ClipboardTool.Domain/PanelModes/ExternalClickRules.cs`：三步判定 `ShouldDockOnOutsideClick`
  （面板可见 + 点击晚于呼出 + 明确在面板物理矩形外）、时间窗纯判定 `HidesOnClick`

  「几何读不到不动作」等 legacy 语义钉子）。
- `ClipboardTool.Infrastructure.Windows/MouseHook.cs`：WH_MOUSE_LL 钩子线程（消息泵 + WM_QUIT
  退出）→ 有界队列（64，满载丢弃，绝不阻塞系统钩子链）→ 转发线程 `Pressed` 事件。
  **回调只记录**（物理坐标 + `Environment.TickCount64` 钩子内取的时刻）入队即返回
  （ADR-0004 防线）；左/右/中/侧键按下均上报（legacy 口径）；委托存字段防 GC。
- `PanelCoordinator.Show()` 开头记 `_shownAtMs`（legacy show_on「先记时刻再动窗口」同序）；
  `App.DockIfClickedOutside` 归队 UI 线程判定，命中走 `DockPanel(restoreFocus: true)`
  （与 Esc 停靠同一编排）；输入态不豁免、多击连点无去抖（legacy hide 统一路径口径）；
  `OnExit` 释放钩子。`PanelWindow.Hwnd` 转 public、`WindowPlacer.TryGetPhysicalRect` 新增。

**语义对齐（以 legacy 为准，不确定处的保守取舍已注明）**
- 浏览态与搜索/备注编辑态点击外部均停靠（legacy hide 统一路径，逐层退输入态发对退出事件）；
- 圆角外透明区不参与停靠决策（legacy hit_test 矩形口径；该区点击经分层窗口 alpha 穿透到
  下层=②已达成项，P5/ADR-0006）；

**自动化证据**

- 真机 E2E `tools/E2eT17`（SendInput 真实点击 + UIA 面板可见性回读，2560×1600@175%）：
  判据A 呼出后点击面板外 → 3s 内停靠 PASS；判据B 呼出瞬间连点外部 8/8 轮面板保持显示；
  判据C 搜索态点击面板外 → 停靠 PASS；判据D 第二实例投递后自行退出（exit 0）且原实例
  面板呼出（Standards 1 异步投递改动后的行为侧冒烟）；无残留进程（自动清理）。

**判据B 判别力负控（如实记录）**
临时禁用时间窗（`shownAtMs=long.MinValue`）复跑 E2E：8/8 轮同样 PASS——本机注入时序下
「点击转发处理」几乎恒先于「WM_HOTKEY → Show」执行（no-op 路径，面板不可见不动作），
未命中「Show 先于点击处理」的竞态窗口，故 E2E 判据B 对时间窗**无判别力**，只能证明
「呼出瞬间连点外部不误收」的行为级冒烟。时间窗的判别性证据以 Domain 单测为准
（`点击早于呼出不收起_晚于呼出才收起` 等例）；这与 legacy 的现场观察一致——该路径
「机器空闲时按下先到判为不动作」，只在开机高负载那一刻复现。跨机高负载真机复核留人工。
