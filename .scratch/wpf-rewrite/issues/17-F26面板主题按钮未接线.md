# 17: F26 面板主题按钮未接线（点击落入搜索井进搜索）

Execution: claimed (主会话, 2026-10-04)——用户真机报告。

## 事实

用户报告：搜索框内的亮暗色切换按钮点击之后会进入搜索框而不是切换亮暗模式。

排查确认：T07 落地了 ThemeService（三态循环/落盘/两路分派）与托盘「主题」子菜单，
但搜索井内主题按钮停留在占位 Border（XAML 注释「三态切换逻辑归 T07」）——图标画的是
跟随系统（显示器），无任何点击行为。点击该区域命中 SearchWell 背景，井的
`PreviewMouseLeftButtonDown`（隧道事件，祖先先至）触发 `OnSearchWellPress` →
浏览态 `SearchActivationRequested` → 进入搜索态。即用户所见现象。

legacy 规格真源（04-reference/legacy/README.md「操作」节）：
搜索井右侧、空格提示左侧主题按钮，点击按**亮色 → 暗色 → 跟随系统 → 亮色**循环；
太阳/月亮/显示器图标表示当前偏好，悬停提示当前与下一态；搜索态下按钮仍可用，
切换保留搜索文字与输入焦点；**浏览态点击按钮不会进入搜索**；与托盘子菜单同步。
