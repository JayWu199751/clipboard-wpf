# 12: T08 提权与安装

## 功能编号

F35（提权与清单）、F36（计划任务与开机启动）、F38（NSIS 安装包）、F39 收尾配合。

## 阻塞

- 11：T07 系统集成

## 目标（可运行结果）

**清单**：release requireAdministrator、debug asInvoker、PerMonitorV2 与 Common-Controls 6 保留；
正式 UI 无管理员开关/提权提示；直接 exe UAC 与计划任务静默入口区分。
**静默启动通道**：计划任务 ClipboardToolElevated（最高权限）为常驻提权入口；开机启动由同一任务登录触发器实现；
autoStart 是持久化**意图**、任务与触发器是**事实**，二者不一致靠开关或下次提权启动收敛；
关闭自启移触发器但保留静默按需通道；升级更新任务 exe 路径；任务 XML 路径含引号处理。
**NSIS**（按 ADR-0001：自包含、新产品身份）：GUI 发布 exe + x64 perMachine、提权启动、快捷方式、
卸载移除任务/快捷方式但**默认保留用户存档**（明确说明）；升级重启后功能可用。
