# 03: T02 文字复制并粘贴闭环

## 功能编号

F01（文字记录）、F02 文字侧、F09–F10（监听与占用）、F11–F13（粘贴链路）、F14（呼出键）。

## 阻塞

- 01：空 WPF 骨架与 HUD
- 02：P2 提权焦点恢复试验（FocusAdapter 按其结论实现）

## 目标（可运行结果）

一条真实链路端到端可用：复制文字 → WM_CLIPBOARDUPDATE 通知 → 序列号基线判定 →
独占读取（字节取完立即关闭、解码在独占段外）→ Application.HistoryService 记录 → HUD 卡片出现 →
Enter/双击触发六步粘贴链路（content_of → write_clipboard → settle_after_copy → focus_target →
restore_and_paste → hide_after_paste，成功才停靠）→ 四种结果文案单源。
失败路径全部可测：条目不可用/写失败短路、占用 50ms 显式重试不清基线、事件源失败退 600ms 轮询、
自己写入同步基线不重复记录、无快照/恢复失败/注入失败分开提示且面板保持可见。
本票内定案「模式单一串行写入者 = UI Dispatcher 还是专用 executor」并写 ADR。

## 红绿测试

- PasteChain 协议测试：迁移 legacy paste_chain 9 例的顺序与短路分支（Domain 层、不经 UI）。

## Answer

T02 交付完成（提交 0919efd）。一条真实链路端到端可用：复制 → WM_CLIPBOARDUPDATE → 序列号基线判定 →
独占读取（字节取完立即关、解码在段外）→ HistoryService 记录 → HUD 卡片 → Enter/双击 →
六步粘贴链路（content_of → write_clipboard(+原子基线同步) → settle_after_copy(提升) → focus_target →
restore_and_paste → hide_after_paste，成功才停靠）→ 四种结果文案单源渲染。
线程模型按 ADR-0004 落地：粘贴链整体进 ModeExecutor 专用线程，UI 只发具名意图、经 Dispatcher 渲染事实；
剪贴板操作全部经进程内独占段串行；「UI 不 Wait」「占用绝不当空接受」两防线显式保持。
失败路径可测且分开提示：条目不可用/写失败短路、无快照/恢复失败/注入失败各自文案且面板保持可见。
