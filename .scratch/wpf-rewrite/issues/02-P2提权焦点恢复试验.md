# 02: P2 提权目标焦点恢复试验

## 阻塞

None（可立即开始；结论阻塞 03 文字闭环票）。

## 问题

提权（管理员）进程能否向普通与**管理员**目标窗口恢复焦点并注入 Ctrl+V？
资料包契约（02-spec/02 §2）：恢复/注入失败分开报、目标失效必须取消注入、
SetForegroundWindow 返回值不是唯一事实要回读归属、UIPI 阻断未必能从 GetLastError 判断。
本机验证范围与 [P1 已证结论](../../../prototype/p1-focus-noactivate/REPORT.md)（普通→普通）的差距就是本试验。

## 成功/失败判据

1. 管理员试验进程 → 普通记事本：焦点恢复 + 注入成功，剪贴板内容落在目标。
2. 管理员试验进程 → 管理员记事本：同样成功（UIPI 允许高→低完整性注入，实测确认）。
3. 目标句柄失效（关闭窗口/复用校验 PID/TID）：零注入，restore/paste 阶段分开报。
4. 恢复最小化目标、快速路径（目标仍前台且焦点未变时零操作）各有一条证据。
5. 失败路径文案与状态可观测，不静默降级为「当前前台随便粘贴」。
