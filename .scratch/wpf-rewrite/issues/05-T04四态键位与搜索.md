# 05: T04 四态键位与搜索

## 功能编号

F18（导航）、F19（重复）、F20（四态让位）、F21（IME）、F22（搜索）、F23（高亮）、F14 呼出重置语义补全。

## 阻塞

- 04：T03 旧档加载与身份落位

## 目标（可运行结果）

面板四态（浏览/搜索/备注编辑/捕获，备注态编辑器本票先占位）的键位状态机：
目标键集合按模式推导、与已生效键集合做差量注册/注销（HotkeyExecutor）；
↑↓ 长按重复、释放或停靠即停、边界停住；搜索态导航键让位给输入框；
中文 IME composition 期间全部导航键让位、组合结束恢复，退出输入态不留旧键、不误发粘贴 Enter；
搜索：120ms 防抖（旧查询取消）、空白分词、多词 AND、大小写不敏感、跨正文+备注+来源名/标题/路径、
空查询全量、结果保持历史顺序不按匹配度重排；正文与备注命中高亮、原文可拼回；
查询变化选中第一项、结果缩短夹紧索引；清除按钮保焦点；Esc 先退搜索再停靠。
呼出重置：选中第一项、退搜索、清查询、清焦点错误与备注编辑。

## 红绿测试

- 四态 × 键位目标集合全矩阵 + 差量推导 + 注册失败不上账。
- 让位矩阵：空格/Z/Del/B 在各态归属；捕获态连呼出键也让位。
- 防抖与取消：旧查询不得覆盖新结果；高亮 spans 与原文拼回。
- 选中夹紧与边界停住。
