# 08: P4 变高卡片虚拟化试验

## 阻塞

None（可立即开始；结论阻塞 09 图片链路票）。

## 问题

VirtualizingStackPanel + Recycling 在**变高**图片卡（150 DIP 缩略图 + 三行文字 + meta）下是否可靠：
滚动测量正确（无跳动/空白）、键盘导航选中项完整可见（保持选中项可见不变式：滚到顶部是 scroll-padding
留白内侧、底部允许到页脚分隔线）、返回顶部回到初始留白、插入置顶/新条目不丢行为；
实际 realized containers ≈ 可视数 + 有限缓存（微软文档：不能只看 XAML 虚拟化属性，要数容器）。

## 成功/失败判据

1. 200 条混合卡（文字+4K 图占位）真实滚动：选中项全程完整可见，无重复解码风暴（解码请求计数）。
2. 视觉树数容器：数量接近可视 + 少量缓存页；Recycling 生效（容器复用证据）。
3. 高频导航（长按重复）滚动即时跟随；顶端保护留白、底部到页脚分隔线。
4. 变高测量不产生滚动位置漂移（前后同条目位置一致）。
