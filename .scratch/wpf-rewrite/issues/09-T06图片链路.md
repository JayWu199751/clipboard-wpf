# 09: T06 图片链路

## 功能编号

F02 图片侧、F05 图片裁剪部分、F42–F44 图卡视觉、F03 图片身份落地。

## 阻塞

- 04：T03 旧档加载与身份落位
- 07：P3 DIBV5 透明截图试验
- 08：P4 变高卡片虚拟化试验

## 目标（可运行结果）

截图/复制图片端到端：剪贴板 DIB →（P3 结论的 DibDecoder）→ PNG 落盘 `<id>.png` →
条目按 PNG 内容 SHA-1 判身份去重（命中沿用原 id 不重写文件）→ 图卡 150 DIP contain + 棋盘格底 + 文件名行 →
**有界缩略图缓存**：按可视区及少量预取加载、解码到实际缩略图物理像素（约 150 DIP × DPI）、
双上限 LRU（至多 32 张且解码像素估算 ≤ 24 MiB）、移除/裁剪/清空立即失效、停靠回收不可见项、
取消旧请求与 id/代次校验防错图、跨线程 BitmapSource Freeze；
复制时写**位图内容**（保透明通道，兼容截图工具/Office），不是文件路径；
列表虚拟化按 P4 结论配置并保留容器计数证据。图片完整内容只在磁盘与复制链路按需读取，
禁止常驻全尺寸 Bitmap/base64。

### E2E 真机验证（2026-10-03 放行后执行：tools/E2eT09，43 项全部 PASS）

方法：T02 E2E 产线思路——真实剪贴板写 CF_DIB/CF_DIBV5 + UIA 定位卡片 + 合成鼠标/滚轮 + WM_HOTKEY 热键 + 文件系统断言；容器计数用 P4 方法，由 `ContainerDiagnostics`（`CLIPBOARDTOOL_E2E_DIAG` 环境变量门控，正常运行零开销）采样 distinct InstanceId 与绑定 index。E2E 前后对真实存档（history.json + images/ 32 文件）做备份/原样恢复，验证无残留进程。

判据① 截图与透明链路：
- 系统截图（GDI CopyFromScreen → CF_DIB）入库，落盘 PNG 与截屏源 1024×768 像素逐一比对零差异。
- 合成透明截图（四角 48px 圆角 alpha=0 + 半透明带 alpha=120 → CF_DIBV5）入库，落盘 PNG 像素保真（圆角/半透明/正文 alpha 与 RGB 全部零差异）。
- 缩略图渲染证据：图卡区域截屏 distinct colors=57347、σ=52.4（棋盘格底 + 图已画，非空白）。
- 同图重复制：身份哈希命中，不新增条目（页脚计数不变）、不重写文件（字节不变）。
- 复制链路保透明：双击图卡 → 剪贴板 CF_DIBV5 回读，480×320=153600 像素零差异（圆角 alpha=0、半透明带 alpha=120 完整保留）——「粘贴到画图/Office」的位图内容已验证，目测观感留人工。

判据② 4K 滚动与容器计数：
- 206 条混合批量入库（2 截图 + 3 占位 + 6 张 4K + 49 变尺寸 + 145 文字 + 1 置顶删除目标），4K 单张入库 360–482 ms（含解码+编码+哈希）。
- 90 批合成滚轮滚动：平均 139.9 ms/批、最大 153 ms（无卡顿告警）。
- 容器计数（滚动窗口段）：realized 峰值 13（可视+有限缓存）、distinct InstanceId=13（Recycling 复用，远小于 200）、最深绑定 index=52、同一 InstanceId 先后绑定不同 index（换绑快照在案，诊断文件留存）。
- 内存观察点：滚动前 WS=303.2/Priv=201.9 MiB → 滚动后 WS=311.8/Priv=208.3 MiB（正式门槛推迟）。

判据③ 裁剪与清空（文件系统断言）：
- 200 上限裁剪：206 条入库后页脚 200、images/ 文件数 55 与存活图片条目一致，6 张最旧 PNG（含 2 张截图 + 1 张 4K）从文件系统消失。
- Del 删条目（WM_HOTKEY 热键路径）：页脚 200→199，撤销窗口（6s）到期后 PNG 从文件系统消失。
- 清空历史：其余 199 条逐条 Del 删除至页脚 0 条，7.2s 撤销窗口全部到期后 images/ 目录无任何残留文件。

附加：重启复核——杀进程重启后 200 条存档重载、缩略图复用磁盘 PNG 正常渲染；重启时剪贴板残留的置顶图被重新录制，身份去重提升、不产生新文件（WIC PNG 编码跨进程/重启确定性的行为面证据）。

E2E 观察点（产品侧）：持续高频 Del（约 20 条撤销窗口并存、容器每 200–400ms 重建）时出现个别 Del 无效（页脚不减），停靠排空撤销窗口后重新呼出即恢复；单项 Del 路径与低频删除无此现象。疑似 Items 重建竞态中 SelectedItemId 短暂失效，不影响单用户正常操作，留观察/后续票。
