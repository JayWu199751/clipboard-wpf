# 普通界面文字改为微软雅黑

2026-10-08，用户测试思源黑体后明确要求「改成微软雅黑」。

## 范围

- 面板和托盘菜单普通文字改用系统安装的微软雅黑（Microsoft YaHei），共用 Font.Sans。
- 字体回退为 Microsoft YaHei → Segoe UI → 系统；不打包或安装微软雅黑字体文件。
- 等宽区域的 Font.Mono 保持原值；现有字号、字重和布局不变。
- 移除刚加入的思源黑体 OTF、来源说明、许可及项目分发配置，同步 ADR。
- 保留上一方案的历史记录并标注替代关系。
- 构建、验证实际字体加载和发布资源，重启为新构建供用户测试。
