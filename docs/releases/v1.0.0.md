# Clipboard WPF v1.0.0

首个 GitHub 发布版本，适用于 Windows 10 22H2 / Windows 11 x64。

- 本地文字和图片剪贴板历史，支持搜索、置顶、备注及删除撤销。
- 全局快捷键呼出，复制并粘贴回原窗口。
- 亮色、暗色、跟随系统主题及托盘菜单。
- 自定义快捷键、开机启动、多显示器和 DPI 支持。
- 完整诊断日志、异常记录与日志轮转。

下载 `ClipboardTool-Setup.exe` 安装，包内已包含 .NET 10 桌面运行时。安装和正式版运行需要管理员权限；卸载默认保留 `%APPDATA%\ClipboardTool` 中的数据。

485 项自动化测试通过，全部人工验收项由用户确认通过。用户使用一周反馈占用约 100 MB 并接受当前表现；该观察未指定内存采样指标。
