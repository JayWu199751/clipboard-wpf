# Clipboard WPF v1.0.1

修复重启电脑并开机启动后，快捷键与托盘菜单能够响应，但剪贴板面板被其他窗口遮挡的问题。

- 每次呼出重新刷新实际置顶顺序，浏览面板不激活、不抢输入焦点。
- 托盘菜单或第二实例再次显示已呼出的面板时，也会刷新位置与置顶，保留输入模式和原焦点快照。
- 诊断日志补充原生窗口落位调用结果，避免调用失败被已有可见矩形掩盖。

487 项自动化测试通过，Release 构建通过，真实 WPF 隔离验证覆盖被遮挡后从托盘再次显示的场景。安装后的重启登录启动、物理快捷键和托盘操作仍待用户验收。

下载 `ClipboardTool-Setup.exe`。升级前从托盘退出旧版本，再运行安装包；现有剪贴板历史和设置保留。安装包包含 .NET 10 桌面运行时，适用于 Windows 10 22H2 / Windows 11 x64，安装和正式版运行需要管理员权限。
