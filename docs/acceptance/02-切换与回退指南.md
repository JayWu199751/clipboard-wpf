# ClipboardTool 切换与回退指南（旧 Tauri 版 → 新 WPF 版）

日期：2026-10-04。适用：Windows 10 22H2+ / Windows 11 x64。
**正式切换由用户执行；本文是可 review 的操作文档，已按同步骤完成一次副本演练**（结果见
[migration/migration-drill-log.txt](perf/../migration/migration-drill-log.txt)）。

## 背景与前提（ADR-0001）

- 新版是**新产品身份**（独立 GUID/安装包），不会覆盖升级旧 Tauri 版；两代**不得同时运行**
  （争抢呼出键、共写同一存档目录 `%APPDATA%\ClipboardTool`）。
- 切换路径 = 备份存档 → 退出并卸载旧版 → 安装新版 → 验证 → （异常时）回退。
- 新版安装包自包含 .NET 运行时（约 60MB），无需预装 Desktop Runtime；安装需管理员（perMachine）。
- 存档格式两代同契约：`clipboard-history.json` + `images/<id>.png` + `settings.json`，
  位置 `%APPDATA%\ClipboardTool`——切回旧版数据不丢。

## 第一步：备份存档

```powershell
Copy-Item "$env:APPDATA\ClipboardTool" "$env:USERPROFILE\Desktop\ClipboardTool-backup-$(Get-Date -Format yyyyMMdd)" -Recurse
```

确认备份目录里有 `clipboard-history.json`（以及有条目时 `images\*.png`）。

## 第二步：退出并卸载旧版

1. 旧版托盘图标右键 → 退出（确保进程完全退出：任务管理器确认无 `clipboard-tool.exe`）。
2. 设置 → 应用 → 已安装应用 → ClipboardTool → 卸载；
   或运行 `C:\Program Files\ClipboardTool\uninstall.exe`。
3. 卸载**不会删除存档**（`%APPDATA%\ClipboardTool` 保留——T08 已验证卸载器行为；即便被清，第一步备份兜底）。
4. 注意：旧版遗留的注册表卸载键若在卸载后仍存在（控制面板仍显示一条），属旧版卸载器残留，
   不影响新版安装与运行，可忽略或手动删除
   `HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Uninstall\ClipboardTool`（64 位视图）。

## 第三步：安装新版

1. 运行 `ClipboardTool-Setup.exe`（新版 NSIS 自包含包）。
2. 安装完成后新版自动启动（提权运行，安装器已注册计划任务 `ClipboardToolElevated` 作为
   静默启动通道与开机登录触发器）。
3. 旧版设置（呼出键/主题/自启意图）随存档目录的 settings.json 延续。

## 第四步：验证清单（切换验收）

- [ ] 托盘图标出现；Ctrl+Shift+V（或原呼出键）呼出面板，Esc 停靠。
- [ ] 历史条目完整：条数、置顶块在前、备注、图片缩略图正常（旧档读取）。
- [ ] 复制一条文字 → 面板出现新条目；Enter 粘贴到记事本成功。
- [ ] 复制一张截图 → 图片卡片出现；双击图片卡片 → 画图粘贴成功（透明背景保留）。
- [ ] Del 一条 → 撤销 toast → 撤销生效；再 Del 一条 → 等 6 秒 → 重启后确认已删。
- [ ] 搜索：空格进搜索、多词 AND、Esc 先退搜索。
- [ ] 主题：搜索井按钮循环亮/暗/跟随系统；跟随模式下改系统主题面板/托盘同步变色。
- [ ] 开机启动：托盘菜单勾选后（或已勾选），**重启机器**验证开机后热键/托盘左键/托盘菜单三路呼出。
- [ ] 清空历史（托盘）→ 确认清空（演练机可跳过）。

## 回退方法（切换后异常时）

1. 托盘退出新版（确认无 `ClipboardTool.exe` 进程）。
2. 卸载新版：设置 → 应用 → ClipboardTool（新条目）→ 卸载（卸载器会删除计划任务与快捷方式，存档保留）。
3. 重新安装旧 Tauri 版安装包（用户留存的原安装包；旧版读同一存档目录，新版写入的档格式与旧版兼容，
   演练已验证「新→旧」往返：条目/置顶/备注/PNG 全部可读）。
4. 启动旧版，验证历史完整；如需恢复到切换前精确状态，用第一步备份覆盖回
   `%APPDATA%\ClipboardTool`（先退出两代程序）。
