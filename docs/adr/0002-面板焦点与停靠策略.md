# ADR-0002：面板焦点与停靠策略

日期：2026-10-03。状态：已接受（依据 P1 试验证据）。

## 背景

面板必须做到（F15 与 legacy 同域契约）：浏览态不抢焦点、输入态可聚焦、停靠是屏外驻留而非销毁、
呼出落地需 OS 回读验证。WPF 能否等价实现是 T01 的阻塞试验 P1；证据见
[prototype/p1-focus-noactivate/REPORT.md](../../prototype/p1-focus-noactivate/REPORT.md)（2026-10-03，Win11 26300 x64，9/9 自动判据通过）。

## 决策

1. `PanelWindow` 浏览态常驻 `WS_EX_NOACTIVATE` + `WS_EX_TOOLWINDOW`（WPF `ShowInTaskbar=False`），
   显示用 `ShowActivated=False`；窗口永不销毁，停靠=移出工作区（旧版策略：右缘外 20 DIP，y 取工作区顶，
   无显示器兜底 -10000,0），同 HWND 复用。
2. 进入输入态：清 `WS_EX_NOACTIVATE` → 聚焦输入控件 → 直接激活失败时 `AttachThreadInput` 级联激活；
   退出输入态恢复 `NOACTIVATE` 并归还焦点快照（完整恢复链由粘贴链路负责，提权目标归 P2 验证）。
3. 浏览态键位不依赖窗口焦点：导航键经 `RegisterHotKey` 全局注册、按模式让位（F18–F20）；
   窗口焦点只在输入态存在。

## 后果

- T01 的 PanelWindow 按此实现，不再试验其他焦点方案。
- 点击穿透（圆角外）与多显示器/分数 DPI 行为不在本 ADR 范围（P5 试验与 T01 真机项）。
- `--manual` 待人工项：点击卡片不激活、IME、多屏呼出。
