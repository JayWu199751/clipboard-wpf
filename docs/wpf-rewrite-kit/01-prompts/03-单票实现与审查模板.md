## 最终审查提示词

> 使用 `code-review` 从基准 [提交] 审查 ClipboardTool WPF 重写；并列给出 Standards 与 Spec 结论。Spec 以资料包 F01–F48、平台契约和已确认 ADR 为准，逐条核对实现/测试/真实验收证据。特别检查 Enter/双击是不是同一粘贴服务；停靠是否在注入成功之后；失效目标是不是取消而不是改粘当前前台；注册键集合是否依系统回执；输入态/IME 是否让位；旧 JSON/路径/毫秒/备注兼容；占用读有没有破坏基线；虚拟化是否真生效；图片缓存是否有界且可失效；复制成功后日志与假资源是否收尾。安装和跨权限行为需要真机证据。发现按优先级给具体触发、影响、文件和最小修复；不能用检查清单全部打勾替代实际审查，也不能因 UI 好看标功能等价。

## 续接提示词

> 继续 ClipboardTool WPF 重写。上次完成：[票号/提交]。输入规格：[路径]。读取 handoff [路径] 和本次票 [路径]，核对 git 状态与依赖完成证据；从票里恢复事实，不根据会话标题推测。先报告本票可运行目标，再按 implement/tdd 实现。已有功能/平台契约保持，未完成真机验收继续留在矩阵中。
