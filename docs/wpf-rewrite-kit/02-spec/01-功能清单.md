## 当前事实边界

现有正式测试基准是 49 个渲染层规则 + 107 个 Rust（另 2 个 ignored 真机探针）+ 18 个浏览器回归。这是原版证据，不是要求新版恰好凑同数量。覆盖同等行为与失败路径才是判据。

原版 README 还保留一条「截图详情正常」历史描述；当前 App 已无详情区，不能借此恢复旧功能。原版关于开机三路呼出、任务栏图标、提权裸键、系统主题与分数 DPI 的待真机问题仍是待验证，重写须将对应场景纳入验收。跨进程不能原子抓住每个极快剪贴板中间态；连续复制指标须注明间隔，避免「通知队列 = 全部中间内容」的隐性承诺。

本轮未加入：云同步、账号、历史导入导出 UI、OCR、文件历史、富文本/HTML 语义、密码排除规则、分类标签、可调历史上限 UI、鼠标拖拽改尺寸。若未来需要，另开规格与 ticket。
