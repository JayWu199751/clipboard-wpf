# HUD 界面还原规格

权威视觉事实是基准 `tauri/src/theme.css`、`styles.css` 与当前 React 组件。原型直接复用两份 CSS 和当前 SVG 符号；`docs/screenshots/` 是较早截图存档，包含已退役形态，不能盖过当前源码。

## 形态和尺寸

面板在光标所在屏幕的工作区**居中**，不随光标坐标紧贴摆放。全屏物理高/DPI 得 DIP 高，再按 7/8 算面板高，宽是高的一半，四舍五入。例如 1080p@100% → 473×945 DIP，1440p@200% → 315×630 DIP，1440p@175% → 360×720 DIP。浏览器原型用可视高度×7/8 近似，真实显示器/任务栏由 WPF 适配器计算。

| 部位 | 还原值/布局 | WPF 对应 |
|---|---|---|
| 外壳 | 36 DIP 圆角、四边 1 DIP 安全留白、2 DIP #757575 实线，两主题同色；原生阴影关闭 | 透明或定制无框壳 + Border；UseLayoutRounding/DPI 真机回读；圆角 hit test |
| 三行 | 60 / * / 30 DIP | Grid.RowDefinitions |
| 搜索头 | 左右 12 DIP，搜索井高 36、胶囊两侧半圆，搜索图标 15，主题按钮 24/图标15 | Border CornerRadius=18 + TextBox + 图标按钮 + 键名 chip |
| 列表 | 上左右 12、下16、卡片间8；顶部12可视保护，不贴圆角带 | 虚拟化 ListBox 内 padding/滚动可视区规则 |
| 卡片 | CornerRadius12，1 DIP细线，内边距上下12/左右16；不得压缩图卡或撑宽 | 自绘 ListBoxItem ControlTemplate |
| 正文 | 字号13，行高约20.15，原换行、长词折行、最多三行 | 三行可视文本投影；完整正文用于搜索/复制 |
| 图片 | 150 DIP 高，contain 居中，6 DIP圆角，棋盘格底；后文件名，再meta | Image Stretch=Uniform，缩略图限尺寸解码，透明 DrawingBrush 棋盘 |
| 文件名 | 字号12，mono，单行省略，缩略图后12 DIP | TextBlock + CharacterEllipsis |
| meta | 上间距8，高16，mono字号10.5，gap6；来源·时间·图钉·备注 | 水平轻模板，末段省略；源应用无额外图标 |
| 备注编辑 | 同meta高16，字号10.5，内行高14、左右padding8；1 DIP描边+3 DIP柔光，单一圈；上下有4 DIP绘制余量 | TextBox自定义模板，抑制默认主题环，不改变布局高度 |
| 滚动指示 | 4 DIP宽、右5、thumb最小28，900ms淡出；不占卡片布局 | 覆盖层指示条，列表原生条隐藏但滚动逻辑保留 |
| 页脚 | 左右16、顶部细分隔线、mono10.5；六组间8、组内4，chip高16/字9.5；400/340窄档再收紧 | 键位注册表驱动提示，按面板实际宽度触发 VisualState |
| toast | 居中胶囊，高34，下距48；成功绿/删除失败红，动作可点，多条栈 | 面板内overlay；状态播报，撤销生命周期独立于可见性 |
| 捕获层 | 整面板遮罩；中央卡宽320/圆角10/padding24，标题15、正文12，胶囊取消 | Overlay Grid，可输入键组合，窄窗宽度钳紧可用空间 |

图卡内部间距应复现**当前数值**：thumb→文件名是12 DIP，文件名→meta当前 CSS 是8 DIP（部分旧 README 文字仍把两处都写12）。以 styles.css 为准，不复制陈旧描述。

原型唯一额外的窄窗视觉补偿：315 DIP 面板中，当前源码的页脚即使套原400/340规则仍会溢出约4.5px。本原型在≤340的容器内把页脚左右留白收为10、文字9.5、组距3，保留全部六组；标准宽度保持正式样式。此项作为 WPF 窄窗验收参考，不表示原版已修复。浏览器容器查询替代原版基于窗口宽度的媒体查询，是为面板嵌在演示网页中保持正确断点。

| 外壳描边 | #757575 | #757575 |

完整 token 随 `03-prototype/assets/theme.css` 与参考快照提供，迁移为两套 ResourceDictionary；字体 sans=Inter→Segoe UI→系统，mono=JetBrains Mono→Cascadia Code→Consolas。当前应用没有打包 Inter/JetBrains Mono 字体，原型使用相同 fallback。不能宣称 HTML 与 WPF 在字体栅格化上逐像素相同；以字号/行轨/留白/密度与实际字体截图比较。

SVG 为 24-grid、stroke1.75、round cap/join，同族太阳/月亮/显示器/搜索/图钉/层/叉/勾；WPF 用 Geometry/Path，保持笔画与位置，不改 emoji 或随意库图。卡片不加复制胶囊、类型 chip、来源 logo；不加标题栏、侧栏、详情、毛玻璃或装饰渐变。当前图片 letterbox 区原样保留已有底，后续 token 化是实现调整而非主题重设计。

## 状态和动效

选中用 tint+细线；鼠标 hover仅细边加深；复制闪光500ms绿→选中色；卡片状态100ms、toast入240ms/出160ms、普通toast2600ms。高频导航不对尺寸/位置做延迟动画。系统减少动画时关闭。空历史/无结果不同提示，备注/错误页脚覆盖普通组。

原型演示的是浏览、搜索、备注、捕获、空历史、无结果、粘贴失败、删除/撤销、三态主题及模拟托盘。右侧演示工具、状态读数、停靠后的重开提示是**原型辅助**，不能迁移为正式 UI。没有持久化或系统副作用；页面内键盘输入需要浏览器获得焦点，不能验证真实全局裸键。

还原优先级：交互/焦点契约→布局与边框可见→文字/图片密度→色与图标→微动效。验收以当前源码的规格与基准原型截图为准，分数 DPI 下边框/圆弧/焦点环逐档眼看；WPF 实现不能仅凭属性值正确就标通过。
