基准日期：2026-10-03。原实现：Tauri 2 + React 19 + Rust；基准提交：`b05ba281438f713c676b94d3de89f679cfc383cd`。本次交付的是重写提示词、行为规格与 HTML 原型，尚未实现 WPF 应用，也没有测得 WPF 内存结果。

## 最快开始

1. 将整个 `wpf-rewrite-kit` 文件夹放在仓库的 `docs/` 下，入口为 `docs/wpf-rewrite-kit/README.md`，保留子目录结构。本仓库已按此布局放置。
2. 若希望一次复制全部内容，使用 [01-prompts/00-完整版提示词.md](01-prompts/00-完整版提示词.md)：已汇编总提示词、48项功能、平台契约、架构/性能、视觉、Matt阶段和验收。若整个资料包已经放在新项目里，也可用较短的 [01-prompts/01-重写总提示词.md](01-prompts/01-重写总提示词.md) 引导按需读取。
3. 按 [01-prompts/02-Matt技能分阶段提示词.md](01-prompts/02-Matt技能分阶段提示词.md) 推进每一阶段；每次实现一个自包含 ticket，保留验收证据。
4. 双击 [03-prototype/index.html](03-prototype/index.html) 查看交互原型。全部资源本地化，无需安装依赖、联网或构建。入口默认随浏览器系统主题；通过右侧工具栏和面板主题按钮比较亮暗。

## 原型操作

面板中：单击选中，双击或 Enter 模拟复制并粘贴；↑↓导航；空格进入搜索；Z 切换置顶；B 内联编辑备注；Del 删除且 6 秒内可撤销；Esc 退出输入态或停靠。主题按钮按亮色 → 暗色 → 跟随系统循环。

右侧为**演示工具**，不是正式应用 UI：呼出/停靠、模拟托盘、空历史、示例历史、复制失败、删除失败和系统主题模拟。托盘里可演示换键、开机启动、清空和退出。顶部状态读数用于看清四态、主题、选中项与待删除数量。重新载入恢复示例，不触碰系统剪贴板、计划任务或 `%APPDATA%`。

URL 支持 `?theme=light` / `?theme=dark` / `?theme=system`，及 `?scene=empty` / `?scene=capture` / `?scene=error`。浏览器中的 Ctrl+Shift+V 可能被浏览器占用，使用演示「呼出」按钮也能体验。

## 范围与事实

当前正式 UI 以 `tauri/src/` 为准；`clipboard-app/` 是较早的界面来源，不作为恢复已删除功能的依据。截图数据采用虚构示例，原型图片是本地 SVG 演示素材。原型展示的系统效果都是模拟；真实提权、输入注入、跨屏 DPI、开机启动与安装包需在 WPF 实现完成后人工验收。

低内存是重写动机，不能从「改用 WPF」直接推导结果。目标采用原生 WPF、可视区虚拟化、图片按需解码和有界缓存；先建立旧版基线，再用同机器同数据比较。具体指标和记录方法只在性能计划与验收文件维护。
